Chord Rider Pro v1.8.0

Changes:
- Mic Check is now an on/off mic-test toggle.
- Lead/Bass bars have Copy / Paste / Clear. Copy/paste works between bars and adapts note timing if the destination resolution differs.
- Vocal FX remain non-destructive and can be edited after recording.
- Vocal dry WAV masters now support authenticated cloud sync through Cloudflare R2 (AUDIO binding).
- Studio Export adds per-part, drums, and project-notes checkboxes and creates a ZIP. Project notes are included only when checked; selected vocal parts include their active dry WAV.

Cloud setup required once:
1. In Cloudflare, create an R2 bucket named: chord-rider-pro-audio
2. Deploy this repo. wrangler.jsonc already binds that bucket as AUDIO.
3. Save a project while signed in. Existing local vocal takes are uploaded automatically.
4. On another signed-in device, loading/playing a take fetches its WAV from cloud and caches it locally.

Assets were not changed.
